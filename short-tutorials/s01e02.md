# Lammps with MACE on Leonardo Booster

This tutorial is for EuroHPC resource Leonardo Booster.
The reason is on Leonardo, the Nvidia driver version may only support CUDA 12.x, and default MACE pip install will based on cuda 13.x and newest cuequivariance.
which will be fail on Leonardo.

## Prepare lammps and mace source code

```bash
git clone https://github.com/lammps/lammps.git
git clone https://github.com/ACEsuit/mace.git
```

Now you should have `lammps` and `mace` folders in current directory.

## Compile lammps

Summary about the build options and packages for lammps

* BUILD_MPI
* BUILD_SHARED_LIBS
* PKG_KOKKOS
  * Kokkos_ENABLE_CUDA
* PKG_PYTHON
  * Python development files (Python.h, and libpython3.11.so)
* PKG_ML-IAP
  * MLIAP_ENABLE_PYTHON
    - Cython must be found

We create a `build` folder for cmake build process, and compiled code with install to folder `lammps-mace`

pkgs.cmake: (include more packages if you need)

```
# preset that turns on just a few, frequently used packages
# this will be compiled quickly and handle a lot of common inputs.

set(ALL_PACKAGES KSPACE MANYBODY MOLECULE RIGID)

foreach(PKG ${ALL_PACKAGES})
  set(PKG_${PKG} ON CACHE BOOL "" FORCE)
endforeach()
```

```bash
module purge
module load cmake/3.27.9
module load gcc/12.2.0
module load cuda/12.2
module load openmpi/4.1.6--gcc--12.2.0-cuda-12.2
module load fftw/3.3.10--openmpi--4.1.6--gcc--12.2.0-spack0.22
module load python/3.11.7

python -m pip install --upgrade pip setuptools wheel
python -m pip install Cython

mkdir -p build
cd build
cmake ../lammps/cmake \
       -C ../pkgs.cmake \
       -DCMAKE_INSTALL_PREFIX=$(dirname $(pwd))/lammps-mace \
       -DBUILD_SHARED_LIBS=yes \
       -DBUILD_MPI=yes \
       -DPKG_PYTHON=ON \
       -DPKG_ML-IAP=ON \
       -DMLIAP_ENABLE_PYTHON=ON \
       -DPKG_ML-SNAP=ON \
       -DBUILD_OMP=yes \
       -DMPI_CXX_COMPILER=mpiCC \
       -DCMAKE_CXX_COMPILER=g++ \
       -DCMAKE_C_COMPILER=gcc \
       -DCMAKE_Fortran_COMPILER=gfortran \
       -DCMAKE_BUILD_TYPE=Release \
       -DPKG_KOKKOS=ON \
       -DKokkos_ENABLE_SERIAL=ON \
       -DKokkos_ENABLE_OPENMP=ON \
       -DKokkos_ENABLE_CUDA=ON \
       -DKokkos_ARCH_AMPERE80=ON \
       -DKokkos_ARCH_ICX=ON \
       -DKokkos_ENABLE_DEPRECATION_WARNINGS=OFF \
       -DFFT=FFTW3 \
       -DFFT_KOKKOS=CUFFT

make -j 8 install

cd -
```

Recommend unload these module before next step.

```bash
module purge
```

## test MACE with lammps

* Create a `test` folder
* download a MACE model
  * convert to lammps mliap format
* lammps input file
* slurm job script then sent to the queue

### download a mace model
```bash
mkdir -p test
wget -O mace-mp-0b3-medium.model https://huggingface.co/mace-foundations/mace-mp-0/resolve/main/mace-mp-0b3-medium.model
python ../mace/mace/cli/create_lammps_model.py mace-mp-0b3-medium.model --format=mliap

```

### test/in.cu_macr_mliap_kk:

```
# in.cu_mace_mliap_kk

units           metal
atom_style      atomic
boundary        p p p
newton          on

lattice         fcc 3.615
region          box block 0 8 0 8 0 8
create_box      1 box
create_atoms    1 box

# pair_style      mliap unified mace-mp-0b2-small.model-mliap_lammps.pt 0
```

### job.sbatch:

make sure adept flowing with yours

* `lmp` should in the `PATH`
* `liblammps.so` in `LD_LIBRARY_PATH`
* all modules should be loaded
* `lammps_mace_venv` should be activate
* change `EUHPC_XXX_XXX` with your allocation account on Leonardo Booster
* `--qos=boost_qos_dbg` and `-t 30:00` only for testing
* change `-N`, `-n`, `-c` and `--gres=gup:1` if needed

```
#! /bin/bash
#SBATCH -N 1
#SBATCH -n 1
#SBATCH -c 8
#SBATCH --gres=gpu:1
#SBATCH -A EUHPC_XXX_XXX
#SBATCH -t 30:00
#SBATCH -p boost_usr_prod
#SBATCH --qos=boost_qos_dbg ## remove if you run in production

module purge
module load cmake/3.27.9
module load gcc/12.2.0
module load cuda/12.2
module load openmpi/4.1.6--gcc--12.2.0-cuda-12.2
module load fftw/3.3.10--openmpi--4.1.6--gcc--12.2.0-spack0.22
module load python/3.11.7

export PATH=$PWD/../lammps-mace/bin:$PATH
export LD_LIBRARY_PATH=$PWD/../lammps-mace/lib64/:$LD_LIBRARY_PATH
source $PWD/../lammps_mace_venv/bin/activate

ldd $(which lmp)

srun lmp -k on g 1 -sf kk -pk kokkos newton on neigh half -in in.cu_macr_mliap_kk
```
